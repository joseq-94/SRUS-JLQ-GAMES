# step 1- Knowledge question
In your own words, describe what a Binary Search Tree (BST) is.  
In addition, describe two important properties of a BST: depth and height. How are they different?

This is a special data search that uses keys and organize the data in nodes. Each node has a
maximum of 2 child nodes, and the process repeats until finding the right item. The main 
characteristic is that the smaller value goes to the left and the bigger value goes to the 
right. 
The depth is an important properties because is the distance between the root node and a 
specific node. Another propertie is the height, which is the maximum number of edges in the 
path from that node to a leaf node.

# Step 3 - Knowledge Question (20-60 words) 

In your own words, describe what a balanced BST is.

A balanced binary tree is a BST where the height of the subtrees stays almost the same on 
the left and right sides. This avoids one subtree growing only in one direction. 
This balance helps the search, insert, and delete operations run faster and more efficiently.
